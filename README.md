Project Description

The Pharmacy Management System is a database project designed to help pharmacies manage medicines, customers, suppliers, sales, payments, complaints, and medicine requests efficiently.

The system aims to:

Organize pharmacy operations
Store medicine information
Manage sales and supplier invoices
Track stock quantities
Handle customer requests and complaints
Improve data accuracy
Reduce manual work

The project was developed using:

SQL Server
ERD (Entity Relationship Diagram)
Relational Database Design
SQL Queries
